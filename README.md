# stockvision
   A real-time stock market dashboard built with Python and Streamlit.
Features:
- Live Stock Prices
- Stock Comparison
- Portfolio Tracker
- Buy/Sell Simulator
- Top Gainers & Losers
- Latest Stock News
  
  ## Tech Stack
- Python
- Streamlit
- Pandas
- Plotly
- Yahoo Finance API
